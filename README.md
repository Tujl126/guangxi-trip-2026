2026.10.29–11.04 两人休闲行程。

- `index.html` — 可交互行程地图（高德/百度导航、滴滴打车、去哪儿买票/订房）
- `攻略.md` — 完整行程、餐厅、预算和预订清单

直接打开 `index.html` 即可使用；已部署在 GitHub Pages。

## 手机安装（PWA）

手机浏览器打开上面的地址：

- **安卓 / 荣耀**：浏览器菜单 →「添加到主屏幕」或「安装应用」
- **iPhone / iPad**：Safari 分享 →「添加到主屏幕」

安装后会以全屏 App 方式打开。行程页和 Leaflet 会缓存到本地，离线也能看；高德地图瓦片需要网络。更新页面内容后，把 `sw.js` 里的 `CACHE` 版本号 +1 再部署。
